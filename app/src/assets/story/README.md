# Story demo assets

These local assets support the fictional Rina Putri complaint scenario. They are
bundled by Vite and do not make remote requests.

- `rina-avatar.webp`: replaceable fictional customer profile image.
- `leakage-photo.webp`: simulated customer evidence.
- `handover-agreement.webp`: fictional document preview with no real customer data.
- `payment-receipt.webp`: fictional receipt preview with no real transaction data.

Replace an asset in place only with an approved local file of the same purpose.
Do not add real customer data, credentials, account numbers, or remote image URLs.
